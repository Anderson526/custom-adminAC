## Creador

Desarrollado por Anderson Chila.

Portafolio profesional: https://anderson526.github.io/portfolio-profesional/

## Descripción

Este plugin personaliza la experiencia de administración de WordPress para ofrecer una apariencia más profesional, privada y enfocada en la marca del cliente. Permite ocultar elementos del escritorio, cambiar la interfaz de login y aplicar una marca blanca útil para proyectos técnicos o comerciales.

## Lenguaje y stack técnico

- PHP 7.4+
- WordPress 6.0+
- Hooks de administración y login
- WordPress Settings API
- jQuery y wpColorPicker
- CSS para branding visual
- MySQL para almacenamiento de opciones

## Uso

1. Instalar el plugin en wp-content/plugins/.
2. Activarlo desde WordPress.
3. Acceder a la sección del plugin dentro del administrador.
4. Personalizar:
   - logo de login
   - fondo y colores del formulario
   - texto de agradecimiento
   - nombre de la marca
   - ocultar versión de WordPress
   - menús del admin por rol
5. Guardar los cambios y revisar el frontend del login y el panel.

## Casos de uso

- Sitios clientes con marca propia
- Dashboards internos con apariencia limpia
- Agencias que requieren white label
- Entornos con roles y permisos limitados
